# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique ideas and evidence
rather than people, and leave out harassment, personal attacks and
discrimination of any kind. This applies in issues, pull requests,
discussions and anywhere else the project is represented.

## Market discussions

This project is about market risk, so disagreements about the outlook are
expected and welcome. Back claims with data or sources where you can. Don't
use the project's spaces to promote trades, products, paid services or
referral links, and don't present anything here as investment advice.

## Reporting

To report unacceptable behaviour, contact the maintainer privately through
[GitHub's private reporting](../../security/advisories/new) or the contact
details on the maintainer's GitHub profile. Reports are handled
confidentially. The maintainer may remove comments, lock threads or block
accounts that break this code.
